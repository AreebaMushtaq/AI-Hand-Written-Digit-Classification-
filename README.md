# AI Handwritten Digit Recognition

An AI-based handwritten digit recognition web application built using TensorFlow and Streamlit.
Users can draw digits directly on a canvas, and the trained neural network predicts the digit along with confidence scores.

# Features

* Handwritten digit recognition (0–9)
* Interactive drawing canvas
* Real-time AI prediction
* Confidence score display
* Probability visualization

# Technologies Used

* Python
* TensorFlow / Keras
* Streamlit
* NumPy
* OpenCV
* PIL (Pillow)
* streamlit-drawable-canvas

# Dataset

This project uses the MNIST handwritten digit dataset containing:

* 60,000 training images
* 10,000 testing images
* Digits from 0–9
